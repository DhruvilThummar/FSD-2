# Question 1: Session Visit Counter

## Objective
Create an Express.js application that uses sessions to track and display the number of times a user has visited the website.

## Requirements

1. **First Visit**
   - Display "Welcome User!" message
   - Initialize session visit counter to 1

2. **Subsequent Visits**
   - Display the total number of times the user has visited the site
   - Increment counter on each new visit
   - Use sessions to maintain this data

## Implementation Notes

- Use Express session middleware to store visit count
- Persist the counter across multiple page reloads
- Display a clear message indicating visit number
- Sessions should be maintained for each user

## Expected Behavior

**First Visit:**
```
Welcome User!
This is your 1st visit
```

**Subsequent Visits:**
```
Welcome back!
You have visited 5 times
```

## Files to Create

- `answer/app.js` - Express server with session handling
- `answer/index.html` - Display page
