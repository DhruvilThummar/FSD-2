# Question 2: Session-Based Login System

## Objective
Develop a complete session-based authentication system with login, session storage, and logout functionality.

## Requirements

1. **Create Login Form** (`index.html`)
   - Username (uname) input field
   - Password (pass) input field
   - Login button
   - Method: POST

2. **Page Flow**

   **Step 1: Save Session Page** (`/savesession`)
   - Receive username and password from form
   - Store both values in session
   - Display confirmation message
   - Provide "Continue" button
   - Redirect to fetch page

   **Step 2: Fetch Session Page** (`/fetch`)
   - Retrieve and display username from session
   - Retrieve and display password from session
   - Show "Logout" link

   **Step 3: Delete Session Page** (`/logout`)
   - Destroy the session
   - Clear all stored data
   - Redirect to home page

3. **Session Management**
   - Use session middleware to store data
   - Properly handle session lifecycle
   - Ensure logout clears all session data

## File Structure

```
answer/
├── index.html (Login form)
├── index.js (Express server)
└── package.json
```

## Expected Flow

1. User enters username and password → Login page
2. Form submitted → `/savesession` page (stores in session)
3. User redirected → `/fetch` page (displays saved values)
4. User clicks logout → `/logout` page
5. Session destroyed → Redirected to home page
