# Question 1: Cookies Management

## Objective
Create an Express.js application that sets, manages, and clears cookies based on form submission.

## Requirements

1. **Create an HTML form**
   - First Name input field
   - Last Name input field
   - Password input field
   - Submit button
   - Method: POST

2. **Cookie Management Flow**

   **Step 1: Set Cookies** (on `/next` page)
   - Store first name in cookie
   - Store last name in cookie
   - Store password in cookie
   - Display all cookie values

   **Step 2: Clear Specific Cookie** (on `/login` page)
   - Redirect from `/next` to `/login`
   - Clear the "last name" cookie
   - Display remaining cookies (first name and password)
   - DO NOT display the cleared last name cookie

3. **Implementation Requirements**
   - Use POST method for form submission
   - Use Express.js cookie functionality
   - Properly handle cookie lifecycle (set → display → clear → display)

## File Structure

```
q1/
├── answer/

│   └── index.html (Form page)
```

## Expected Behavior

1. User fills form and submits:
   - First Name: John
   - Last Name: Doe
   - Password: secret123

2. On `/next` page, see all 3 cookies:
   ```
   firstName: John
   lastName: Doe
   password: secret123
   ```

3. Redirected to `/login` page, last name cookie is cleared:
   ```
   firstName: John
   password: secret123
   (lastName is gone)
   ```
