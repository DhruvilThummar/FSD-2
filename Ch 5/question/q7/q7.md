# Question 7: Subscription Management System

## Objective
Develop a web application using Express.js with middleware and POST method for user subscription management.

## Requirements

1. **Create an HTML form**
   - Name input field
   - Email input field
   - Subscription checkbox
   - Submit button
   - Method: POST

2. **Login Page**
   - Welcome user by name
   - Display user's email ID
   - Show subscription status

3. **Subscription Flow**
   - **If subscribed:** Display "Thank you for subscribing!" with logout link
   - **If not subscribed:** Display "You can subscribe" with a subscription link
   - **Upon subscribing:** Redirect to subscription page
     - Display "Thank you for subscribing" message
     - Display logout link

4. **Implementation Requirements**
   - Use middleware concept
   - Use POST method for forms

## Expected Flow

1. User fills form (name, email) and selects/deselects subscription checkbox
2. Form submitted → Login page shows user info
3. **If subscribed:** Shows thank you message → Can logout
4. **If not subscribed:** Shows subscription link → Can click to subscribe
5. **After subscribing:** Shows subscription confirmation → Can logout
