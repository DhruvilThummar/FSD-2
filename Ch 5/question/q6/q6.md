# Question 6: Even/Odd Number Checker

## Objective
Develop a web application using Node.js and Express.js that checks if a number is even or odd.

## Requirements

1. **Create an HTML form**
   - Single input field for number entry
   - Submit button

2. **Form Validation**
   - If input is empty: Display "Please enter a number"
   - If input is not a number: Display "Invalid input"
   - If input is valid: Proceed to result page

3. **Result Page**
   - If number is even: Display "Even Number"
   - If number is odd: Display "Odd Number"
   - Provide a "Go Back" link to return to the form

4. **File Structure**
   - Use 2 files: HTML file and JavaScript (Express) file
