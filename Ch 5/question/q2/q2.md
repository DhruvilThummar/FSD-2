# Question 2: Express Form Data Handler (GET Method)

## Objective
Create an Express.js application that accepts form data via GET method and displays it in JSON format.

## Requirements

1. **Create an HTML form** (`index.html`)
   - Input field for first name
   - Input field for last name
   - Submit button
   - Method: GET

2. **Create an Express server** (`example.js`)
   - Set up GET route for the form
   - Create a `/process` route to handle form submission
   - Display submitted data in JSON format on the process page

## Expected Behavior

1. User opens the form page and enters first name and last name
2. Upon submission, user is redirected to `/process` route
3. The process page displays the entered data as JSON:
   ```json
   {
     "firstName": "John",
     "lastName": "Doe"
   }
   ```

## Files to Create

- `index.html` - Form page
- `example.js` - Express server
