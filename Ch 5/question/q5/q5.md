# Question 5: User Login Application

## Objective
Develop a web application using Node.js and Express.js with user authentication.

## Requirements

1. **Create an HTML login form** (`login.html`)
   - Username input field
   - Password input field
   - Submit button
   - Method: POST

2. **Create an Express server**
   - Handle form submission via POST method
   - Validate credentials:
     - **Correct credentials:** Username = `admin`, Password = `1234`
     - **Success response:** Display "Login Successful"
     - **Failure response:** Display "Invalid Credentials" with a link to go back

## File Structure

**Suggested structure based on question folder:**
```
q5/
├── login.html
└── login.js
```

## Expected Behavior

**Valid Login:**
- Username: `admin`
- Password: `1234`
- Result: Display "Login Successful" message

**Invalid Login:**
- Any other username/password combination
- Result: Display "Invalid Credentials" with a back link
