# Question 1: Express Application Structure

## Objective
Create a folder structure for an Express.js application with organized frontend and backend code.

## Requirements

Create the following folder structure under the main `express` folder:

```
express/
├── js/
│   └── 1.js
├── html/
│   └── 1.html
└── css/
    └── 1.css
```

## Tasks

1. Create three subdirectories: `js/`, `html/`, and `css/`
2. Place `1.js` in the `js/` folder
3. Place `1.html` in the `html/` folder
4. Place `1.css` in the `css/` folder

## Instructions for Running

```bash
mkdir -p express/{js,html,css}
touch express/js/1.js
touch express/html/1.html
touch express/css/1.css
```
