# Question 4: Calculator Application

## Objective
Create an Express.js calculator application that performs operations on two numbers.

## Requirements

1. **Create an HTML form** (`calc.html`)
   - Two input fields for numbers
   - Dropdown menu with operations:
     - Select (default)
     - Addition (+)
     - Subtraction (-)
     - Multiplication (*)
     - Division (/)
   - Submit button

2. **Validation Rules**
   - Both input fields must contain values greater than 0
   - If validation fails, display: "Please enter valid numbers"
   - User must select an operation from the dropdown
   - If no operation is selected, display: "You have not selected any formula"

3. **Create an Express server** (`calc.js`)
   - Handle form submission
   - Perform the selected calculation
   - Display result on `/calc` page

## File Structure

```
├── frontend/
│   └── calc.html
└── backend/
    └── calc.js
```

## Expected Behavior

**Valid Input:** `10 + 5`
**Output:** `Result: 15`

**Invalid Input:** `-5 + 3` (negative number)
**Output:** `Please enter valid numbers`

**No Operation Selected:**
**Output:** `You have not selected any formula`
