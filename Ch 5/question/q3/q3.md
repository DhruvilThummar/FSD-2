# Question 3: Message Splitter (GET Method)

## Objective
Create an Express.js application that splits a message by periods and displays each sentence on a new line.

## Requirements

1. **Create an HTML form** 
   - Text area input field for message entry
   - Submit button
   - Method: GET

2. **Create an Express server**
   - Receive message data via GET method
   - Split message by periods (`.`)
   - Display each sentence on a new line

## Expected Behavior

**Input:** `Hello. How are you. I am fine.`

**Output:**
```
Hello
How are you
I am fine
```

## Implementation Notes

- Use `.split('.')` to split the message
- Filter out empty strings
- Trim whitespace from each sentence
- Display results in a readable format on the response page
