# React Vite

## JSX Rules
- Return a single root element
- Close all tags
- Use camelCase attributes
- Pass JavaScript expressions inside curly braces `{}`
- Provide JSX styling as an object using double curly braces `{{ ... }}`
- Use JSX comments:
  - Single-line: `{/* ... */}`
  - Multi-line:
    ```javascript
    {/*
    ...
    */}
    ```
