# Create a component to perform the following tasks:
1. Add a text field and a submit button. While changing the value in the text field, display it below the form in real-time.
2. Display this text field's value in an alert box upon submitting the form.
3. Add a button that handles both click and double-click events:
   - On single-click: Display the message "You clicked once" in an `<h3>` tag.
   - On double-click: Display the message "You clicked twice".
   - The message should be displayed below the button.
