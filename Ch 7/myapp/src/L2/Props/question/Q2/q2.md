# Create a React application using props to pass an object from one component to another.
1. Create a parent component `Example.jsx` (which contains/imports child `Example1.jsx`).
2. Create an object named `Details` containing the student's `name` and `university`.
3. Pass the `Details` object to the child component `Example1.jsx` using props.
4. In the child component, receive the object and display the student's name and university in the format: `"My name is xyz. I am studying in LJU."`
