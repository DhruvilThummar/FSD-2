# Create a React app with routing:
1. `Myreact.jsx` should set up the router and define the routes. Use `Home.jsx` for the home page and `Product.jsx` for the product page. Implement navigation between these routes.
2. When the user clicks on the Home page link, it should navigate to the Home page and display "Welcome to LJU" inside a blue `<h1>` heading. Include a link to the Product page.
3. The Product page displays information (name, price, and image) for 3 products using props. When a user clicks on the Product page link, it should navigate to the Product page and display the info for all three products.
