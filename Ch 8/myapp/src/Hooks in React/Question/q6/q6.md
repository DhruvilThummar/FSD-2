# Create a React app containing a form with fields for Name, Email, Password, Confirm Password, and a Submit button.

---

## Validation Rules:
- When the form is submitted, the Password and Confirm Password values must match. Otherwise, display an error message in an alert box.
- The password length must be greater than 8 characters. Otherwise, display an error message in an alert box.

---

## Success Behavior:
- If the form is submitted successfully, display the entered Name and Email in an alert box.
