# Create context-based components:
1. Create a parent file named `Cp.jsx` and three other component files: `Cp1.jsx`, `Cp2.jsx`, and `Cp3.jsx`.
2. Pass two numbers (`numberOne` and `numberTwo`) from `Cp1.jsx` down to `Cp3.jsx`.
3. Calculate and display the multiplication of these numbers in `Cp3.jsx` using the `useContext` hook.
