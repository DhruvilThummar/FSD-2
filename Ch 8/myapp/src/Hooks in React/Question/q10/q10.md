# Write a React.js program to perform the following task:
1. Create one parent file named `PC.jsx` and two child component files `C1.jsx` and `C2.jsx`.
2. Pass a `firstName` and `lastName` from `PC.jsx` to `C2.jsx` (via `C1.jsx`).
3. Display a message like "Welcome Abc xyz" in the browser, where "Abc" and "xyz" are the passed first and last names.
