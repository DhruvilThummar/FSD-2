# Use multiple contexts in a React app by creating and consuming them across different components:
- `Comp1.jsx`: Create a context for CSS styling and provide it to `Comp2.jsx`.
- `Comp2.jsx`: Create a context for a string value (e.g., "Student") and provide it to `Comp3.jsx`.
- `Comp3.jsx`: Consume both contexts and display the string value styled with the provided CSS.
