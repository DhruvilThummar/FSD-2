# Question 1: Student Result Application with EJS

## Objective
Develop a web application using Express.js and EJS that displays student results with pass/fail status.

## Requirements

1. **Create an HTML form** (index or form page)
   - Student name input field
   - Marks input field
   - Submit button
   - Method: POST

2. **Create EJS template** (`result.ejs`)
   - Display entered student name
   - Display entered marks
   - Show pass/fail status:
     - **Marks ≥ 40:** Display "PASS" in **green color**
     - **Marks < 40:** Display "FAIL" in **red color**

3. **Create Express server** (`my.js` or `app.js`)
   - Handle form submission
   - Calculate pass/fail based on marks
   - Render result using EJS template

## File Structure

```
q1/
├── answer/
│   ├── my.js (Express server)
│   ├── index.html (Form page)
│   └── result.ejs (Result template)
```

## Expected Behavior

**Input:**
- Name: John Doe
- Marks: 75

**Output (result.ejs):**
```
Student Name: John Doe
Marks: 75
Result: PASS (displayed in green)
```

**Input:**
- Name: Jane Smith
- Marks: 35

**Output (result.ejs):**
```
Student Name: Jane Smith
Marks: 35
Result: FAIL (displayed in red)
```
